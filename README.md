# Bouton Picture-in-Picture (extension Chrome)

Ajoute un bouton Picture-in-Picture (PiP) sur les lecteurs vidéo.

- **YouTube** : un bouton PiP s'ajoute dans la barre de contrôle du lecteur, à côté du bouton plein écran.
- **Autres sites** : un bouton flottant apparaît en haut à droite d'une vidéo quand la souris la survole (iframes comprises).
- **Icône de l'extension / `Alt+P`** : active ou quitte le PiP sur la vidéo principale de l'onglet.

Les sites qui désactivent le PiP (`disablePictureInPicture`) sont contournés.

## Installation (mode développeur)

1. Ouvrir `chrome://extensions`
2. Activer le **Mode développeur** (en haut à droite)
3. Cliquer sur **Charger l'extension non empaquetée** et choisir ce dossier

Pour changer le raccourci : `chrome://extensions/shortcuts`.
